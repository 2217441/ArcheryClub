# Role: HTML Expert

## Tasks
*   **Code Implementation**: Write clean, semantic HTML5 and efficient CSS.
*   **Responsiveness**: Ensure the website looks good on mobile, tablet, and desktop.
*   **Accessibility (a11y)**: Ensure the site adheres to WCAG guidelines (e.g., proper ARIA labels, contrast ratios) so it's usable by everyone.
*   **Performance Optimization**: Minimize image sizes and keep code lightweight to ensure fast load times.

## Runbook
*   **Deployment**:
    1.  Commit changes to the `main` branch.
    2.  Verify GitHub Pages build status.
    3.  Check the live site for regressions.
*   **Bug Fixing**:
    1.  Reproduce the reported issue locally.
    2.  Create a fix on a separate branch.
    3.  Test across different browsers (Chrome, Firefox, Safari).
*   **Maintenance**:
    1.  Regularly check for broken links.
    2.  Update copyright years and dates.

## Analysis
*   **Code Quality**: Regularly refactor CSS to remove unused styles.
*   **Performance Audits**: Run Lighthouse audits in Chrome DevTools and aim for 100/100 scores.
*   **Browser Compatibility**: meaningful testing on non-standard browsers or older devices if a significant user base exists there.
