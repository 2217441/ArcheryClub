# Role: Technical Writer

## Tasks
*   **Documentation Maintenance**: Keep the `README.md`, `technical_roles/`, and other repo documentation up to date.
*   **Content Updates**: Work with the Club Secretary to update the website content (e.g., new committee members, event dates).
*   **Code Comments**: Ensure the HTML and JS code is well-commented for future maintainers.
*   **Constitution Updates**: specific responsibility to ensure the online version of the Constitution matches the official signed document.

## Runbook
*   **Content Refresh**:
    1.  At the start of each semester, review all "About" and "Officers" info.
    2.  Draft updates in Markdown first for approval.
    3.  Apply changes to `index.html`.
*   **Typo Patrol**:
    1.  Periodically proofread the entire website.
*   **Guide Creation**:
    1.  If a new complex process arises (e.g., "How to upload images"), write a guide for it.

## Analysis
*   **Clarity Check**: Review documentation to ensure it can be understood by a first-year student with minimal technical background.
*   **Consistency**: Ensure terminology (e.g., "Archery Club" vs "AC") is used consistently across the site.
*   **Information Architecture**: Analyze if the content is organized logically.
