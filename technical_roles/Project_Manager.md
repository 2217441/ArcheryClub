# Role: Project Manager

## Tasks
*   **Roadmap Management**: Maintain the high-level roadmap for the club's digital presence (website, social media integrations, event registration systems).
*   **Stakeholder Coordination**: Act as the liaison between the Club Officers (President, Secretary) and the Technical Team.
*   **Resource Allocation**: Assign tasks to the HTML Expert, Technical Writer, or other contributors based on availability and skill set.
*   **Sprint Planning**: Organize bi-weekly or monthly planning sessions to prioritize website updates and features.

## Runbook
*   **Weekly Check-in**:
    1.  Review pending issues on the GitHub repository.
    2.  Message team members for status updates.
    3.  Update the project board (e.g., GitHub Projects or Trello).
*   **Crisis Management**:
    1.  If the site goes down, coordinate with the HTML Expert immediately.
    2.  Communicate status to Club Officers.
*   **Onboarding**:
    1.  Grant repository access to new technical members.
    2.  Walk them through the `technical_roles/` documentation.

## Analysis
*   **Risk Management**: Identify potential bottlenecks (e.g., exams week reducing volunteer availability) and plan accordingly.
*   **Velocity Tracking**: Monitor how quickly tasks are completed to improve future estimation.
*   **Impact Assessment**: Evaluate the success of digital initiatives (e.g., did the new online registration form increase sign-ups?).
