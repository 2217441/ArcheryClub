# Role: Product Manager

## Tasks
*   **Vision Definition**: Define *what* the website should do to serve the club's mission (e.g., "The site should not just inform, but convert visitors into members").
*   **Requirement Gathering**: Interview club members and officers to understand their needs (e.g., "We need a way to showcase tournament photos").
*   **Feature Prioritization**: Decide which features (e.g., Dark Mode vs. Event Calendar) provide the most value and should be built first.
*   **User Experience (UX) Oversight**: Ensure the site is intuitive and accessible for all students.

## Runbook
*   **Feedback Loop**:
    1.  Create a feedback form for site visitors.
    2.  Review responses monthly.
    3.  Turn valid feedback into tickets for the technical team.
*   **Launch Communication**:
    1.  When a new feature launches (e.g., new "Hall of Fame" section), draft an announcement for the Club Secretary to send out.
*   **Competitive Analysis**:
    1.  Look at other university club websites.
    2.  Identify trends or features that could benefit the Archery Club.

## Analysis
*   **User Metrics**: Analyze site traffic (if analytics are enabled) to see which pages are most visited.
*   **Conversion Rate**: specific to club sign-ups via the website.
*   **Usability Testing**: Watch a fresh user try to find the "Contact Us" info to identify friction points.
